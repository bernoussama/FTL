Unicode IDNA data read by rust/tools/gen_idna2008.py, which writes
rust/src/idn/tables.rs. These are the 15.1.0 files that libidn2 2.3.8 builds its
own IDNA tables from.

Idna2008-15.1.0.txt
  https://www.unicode.org/Public/idna/idna2008derived/Idna2008-15.1.0.txt
  Unicode 15.1.0, Date 2023-11-13 (IDNA2008 derived property, RFC 5892)

IdnaMappingTable-15.1.0.txt
  https://www.unicode.org/Public/idna/15.1.0/IdnaMappingTable.txt
  Unicode 15.1.0, Date 2023-08-10 (UTS 46 mapping table; only the
  disallowed_STD3_valid and disallowed_STD3_mapped rows are used)
